# 齐天试炼 · 山门余烬

Vite + TypeScript + Three.js 原创第三人称动作游戏。单关古寺庭院，击败唯一的镇庭石狮即通关；生命耗尽可重开。

## 运行

```sh
npm install
npm run dev
npm run build
```

打开终端中的 `/qitian-trial/` 地址。需要支持 WebGL 的桌面浏览器。

WASD 移动，鼠标转向，空格跳跃，J / 左键三段棍术，K 定海神针（冷却），Shift 闪避，Esc 暂停。触屏设备使用左侧虚拟摇杆 + 右侧技能键。Boss 出手前一定先亮预警：地面红圈=巨掌砸地，扇形=巨爪横扫，长条锥形+口中火光=熔岩吐息。看到预警就闪避或走出范围。第三段攻击伤害更高。

## 战斗动画

### 行者：程序化骨骼动画（`src/rig.ts`）

`player.glb` 是 Tripo 自动绑定的蒙皮模型，没有自带动作，`player-loco.glb` 的绑定姿态错误（腿部乱掉），因此不使用 AnimationMixer，改为在骨骼上做程序化姿态动画：

- 姿态在**装备空间**（`TripoOrient` 坐标系，+X 为鼻尖朝向、+Y 向上、+Z 为角色右侧）里编写，再换算到各骨骼自身的局部坐标系。导出器把骨骼命名成 `tripo0_Left_Limb_1` 还是 `tripo::0_Left_Limb_1`（three.js 会删掉 `::`）都不影响。
- 静止姿态在**站立绑定修正之后**采样，所以“零姿态”就是 #21 验证过的站姿，待机动画完全不动腿，脚永远踩在地上。
- 分层混合：待机呼吸 / 跑步 / 空中 / 落地下蹲 / 三段攻击 / 大招 / 闪避 / 受击后仰，各层按权重叠加，再用阻尼推到骨骼上——攻击用高刚度（脆快），待机用低刚度（柔和）。

### 镇山巨兽：预警即判定范围

Boss 是单块静态雕塑，没有骨骼，所以重量感来自预备动作、挤压拉伸、落地尘土和节奏。三个招式统一走 蓄力 → 出手 → 收招：

| 招式 | 蓄力 | 预警 | 判定 |
| --- | --- | --- | --- |
| 巨掌砸地 | 0.95s 后仰抬身 | 地面红圈 + 内圈收缩 | 圈内半径 4.3m，28 伤害 |
| 巨爪横扫 | 0.6s 侧身拧转 | 地面扇形 | 同一扇形 143°/5.4m，22 伤害 |
| 熔岩吐息 | 0.9s 口中火光渐亮 | 地面锥形 + 口部余烬 | 口部锚点为顶点的圆锥，8.6m / 半角 0.21rad，20 伤害/秒 |

火焰从模型包围盒推算出的**口部锚点**喷出（头部前端，`BOSS_MOUTH`），判定用的圆锥和画出来的火锥共用同一组参数：`BOSS_MOVES` 里的数字同时喂给预警、特效和伤害检测，不会出现“看起来没碰到却掉血”。吐息水平方向跟随 Boss 转身（限速 1.1rad/s），横向走位可以躲开。

视觉参考自《黑神话：悟空》的公开截图与视频（打击的预备/停顿/尘土节奏），网格、贴图与特效全部原创，没有使用任何游戏提取资产。

## Image + Blender 美术管线

五张贴图使用 Codex 内置 **image_gen** 生成，转换为 1024×1024 JPEG，保存在 `public/textures/`：

- `sky_dusk.jpg`：中国神话山峦、薄雾与暮色天空，作为背景及低强度环境光。
- `stone_albedo.jpg`：风化古寺石板，用于庭院、石墙和石台。
- `wood_albedo.jpg`：深色旧漆木纹，用于梁柱、长棍和斗笠。
- `cloth_red.jpg`：暗红织物与淡金云纹，用于旗幡和行者衣袍。
- `boss_diffuse.jpg`：灰绿风化石材、细裂纹、金色矿脉，用于石狮。

完整最终提示词和生成来源记录在 `tools/image-prompts.json`。使用内置工具路径，没有调用 API CLI；工具没有提供可选择或验证的“2.5”版本参数，因此不宣称使用了特定 2.5 模型。素材为原创生成，没有游戏提取资产或品牌标志。

`tools/build_models.py` 使用 Blender 建模并导出包含纹理的 GLB：

```sh
/home/box/bin/blender -b --python tools/build_models.py
# 或 blender -b --python tools/build_models.py
```

- `public/models/player.glb`：猴行者、斗笠、分层红袍、卷尾、铜饰长棍，约 8,132 三角面。
- `public/models/boss.glb`：石狮、卷曲鬃毛、獠牙、发光眼睛、仪式胸饰，约 23,258 三角面。

模型使用静态网格及命名的腿、躯干、武器子节点，由现有战斗代码驱动简单动画，无骨骼蒙皮。GLTFLoader 加载后启用开始按钮；所有路径兼容 Vite 部署子目录。现有庭院结构保留并应用生成贴图。

## 验证

```sh
# 先运行 npm run dev
npx playwright install chromium
node tests/smoke.mjs    # 完整对局：加载 → 跳跃 → 打死 Boss → 胜利 → 重开 → 被反击
node tests/stance.mjs   # 站姿回归：骨骼解析、双脚落地、手臂脱离 T-pose，含待机动画 2 秒后复查
node tests/combat.mjs   # 战斗动画与 Boss 招式：跑动迈步、空中收腿、出拳前伸、预警先于判定
```

三个测试都用真实键盘事件驱动游戏，但时间由 `window.__trial.step()` 推进：CI 里是软件渲染（约 1 帧/秒），靠 `waitForTimeout` 等真实时间等不到任何一帧。截图保存在 `tests/`。
